# ゲーム風ポートフォリオ

HTML・CSS・JavaScriptで制作した、RPG風のポートフォリオサイトです。

トップページでは、マップ上のキャラクターを操作して各ページへ移動できます。作品やスキルを紹介するだけでなく、サイト内を探索する体験も楽しめる構成を目指しました。

## 概要

本サイトは、これまでの制作物やスキルを紹介するために制作しました。

トップページをゲーム風のマップにし、建物入口からAbout・Works・Skills・Contactへ移動できるようにしています。各ページも共通のゲームUIで統一し、サイト全体で一貫した世界観を表現しています。

## 主な機能

### キャラクター操作

- キーボードのWASDキー・矢印キーで移動
- タッチ端末ではドラッグで移動
- 建物をクリックまたはタップして各ページへ移動
- 建物の画像と入口の判定領域を分けて配置

### アニメーションと画面演出

- キャラクターの待機・歩行スプライトを切り替え
- `requestAnimationFrame`を使ったマップ上の移動処理
- ページやUIのフェード・アニメーション演出

### 作品紹介

- WorksページでWebサイトやアプリなどの制作物を紹介
- Creativeページで動画・デザインなどの制作物を紹介
- モーダルで作品の説明や関連リンクを表示

### 共通UI

- ゲーム風のヘッダー・フッター
- ページごとに統一したゲームUI
- スマートフォン向けのレイアウト調整

### Contactフォーム

- 名前・メールアドレス・件名・メッセージの入力欄
- 入力内容の検証
- Google Apps ScriptのAPIへフォーム内容を送信
- 送信内容をLINEに通知
- 送信結果をモーダルで表示

## 使用技術

- HTML5
- CSS3
- JavaScript（Vanilla JS）
- `requestAnimationFrame`
- DOM操作
- Git / GitHub

## 実装で工夫した点

### 操作しながらページを回遊できる構成

トップページをマップとして作り、キャラクターを動かして各コンテンツへ移動できるようにしました。建物をクリック・タップして移動する方法も用意し、操作方法を選べるようにしています。

### 見た目と当たり判定の分離

建物画像とは別に入口の判定領域を設けました。画像の形に左右されず、建物の入口に近づいたときにページへ移動できるようにしています。

### 共通UIとページ別ファイルの整理

共通レイアウトやモーダル処理と、ページごとのスタイルを分けて管理しています。ゲーム風のデザインを各ページで共有しながら、ページごとの内容も調整できる構成にしました。

## ページ構成

| ページ   | 内容                                                   |
| -------- | ------------------------------------------------------ |
| Home     | キャラクターを操作して各ページへ移動するマップ         |
| Works    | Webサイトやアプリなどの制作物                          |
| About    | プロフィール・仕事で大切にしていること・現在の取り組み |
| Creative | 動画・デザインなどの制作物                             |
| Skills   | スキル紹介                                             |
| Contact  | 問い合わせフォーム                                     |
